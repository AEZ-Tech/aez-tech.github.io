Ternary Operator ( ? : ) - PHP

Ternary Operator ( ? : ) is a shorthand for an if else block ( making the code more concise ) .

The basic syntax : (condition) ? (value_if_true) : (value_if_false) .

Example : 


            <?php
            
            // ternary operator
            print("<p>Case 1 : </p>");
            $a = False; // Declare Variable
            $a ? print("True") : print("False") ;
            print("<p> a = $a </p>");    
            
            print("<p>Case 2 : </p>");
            $z = True; // Declare Variable  
            $z ? print("True") : print("False") ;
            print("<p> z = $z </p>");
            
            ?>

Output : 


            Case 1 :
            False
            a =
            
            Case 2 :        
            True
            z = 1

----The PHP version used in this example is 8.4.5 ----
